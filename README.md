# 數據背後的王朝密碼——跨時代 NBA 球星得分效率與勝率之相關性研究
一、 分析動機與目的：身為一名熱愛 NBA 的球迷，我觀察到現代籃球與過往陣地戰時代有著顯著的風格差異。從 90 年代的肉搏防守到現代的大三分時代，球隊領袖的個人表現如何轉化為團隊勝利？我決定利用 Python 對此進行量化分析。本研究選取了三個最具代表性的王朝領袖：Michael Jordan (90s)、Kobe Bryant (00s) 與 Stephen Curry (15-18)，探討其真實命中率 (True Shooting Percentage, TS%) 與勝率之間的相關性，並試圖找出「贏球方程式」在不同時代的變遷。

二、 資料處理與分析過程：本專案使用的資料來源為 Kaggle 的 NBA資料集，總行數超過 1,300 萬列。
- 特徵工程與效能優化：原始資料僅包含事件描述，我必須利用邏輯判斷從文字中提取得分、投籃出手數（FGA）與罰球出手數（FTA）。面對龐大的資料量，我棄用低效的迴圈，改採 NumPy 向量化運算 (Vectorization)，將處理速度提升了數十倍，這讓我深刻體會到資料處理中「演算法效率」的重要性。
- 指標建立：我將事件等級的資料聚合為場次等級，並計算核心指標 TS%。相較於傳統命中率，TS% 考慮了三分球與罰球的加權，更能精準衡量進攻效率。

三、 核心發現與結論：數據揭示的時代演進 透過數據對比，我得出以下具備洞察力的見解：
- 贏球效率門檻顯著提升：數據顯示，Jordan 與 Kobe 王朝贏球時的平均 TS% 分別為 0.56 與 0.57，而 Curry 則高達 0.67。這證明了現代籃球已進入「極致效率時代」，球隊必須達到更高的期望值才能確保勝利。
- 勝負對效率的敏感度增加：分析發現，Curry 在勝負場次的 TS% 差距達 19.6%，顯著高於 Jordan 的 14.3%。這代表現代王朝對領袖效率的依賴程度更高，容錯率相對降低。
- 贏球邏輯的轉向：Jordan 王朝在效率波動較小的情況下仍維持高勝率，反映出該時代贏球因子更依賴防守與籃板；而現代籃球則更趨向「純粹效率化」。
